# スマート持ち物リスト (Smart Belongings App)

衣類・ガジェット・バッグ・文房具などの持ち物を美しくスマートに一元管理するWebアプリケーションです。

## 🌟 特徴
- **Googleの警告バーなし**: GitHub Pagesによる快適な全画面Webアプリ表示
- **リアルタイム連携**: Googleスプレッドシート（データベース）とGAS Web APIを介して直接同期
- **すっきり美しいUI**: グラスモーフィズム（すりガラス調）とカード型レイアウト
- **細やかな分類**: 大項目（衣類、ガジェット等）＞ 中項目 ＞ 小項目（スニーカー、Tシャツ等）による整理
- **高速ローディング**: ローカルキャッシュによる即時表示（SWRパターン）

## 📁 構成
- `index.html`: Webアプリ本体（HTML / CSS / JavaScript）
- `Code.gs`: Google Apps Script（バックエンドWeb API）
- `archive/`: 旧バージョンバックアップ

## 🚀 デプロイと設定手順

### 1. Google Apps Script の設定
1. 対象のGoogleスプレッドシートを開き、「拡張機能」>「Apps Script」を開きます。
2. `Code.gs` の内容をエディタに貼り付けて保存します。
3. 右上の「デプロイ」>「新しいデプロイ」をクリックします。
   - **種類**: ウェブアプリ
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員
4. 発行された「ウェブアプリのURL」をコピーします。

### 2. index.html のAPI URL確認
`index.html` 内の `DEFAULT_GAS_URL` に発行されたウェブアプリURLを設定します。
